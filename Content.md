**VI:**. 

Vi is a model text editor used in Unix systems. It uses command mode to navigate and edit, and insert mode to type text.  
Press esc to return to command mode and type : to save/quit options.  
vi filename - open or create a file.  
:w - to save the file.  
:wq or zz - to save and quit.  
:q! - quit without saving changes   
i - insert text before the cursor
a - append text after the cursor
o - open a new line below the current line
O - open a new line above the current line
h, j, k, l - move left, down, up, right
w - move forward one word
b - move backward one word
0 - jump to the start of the line
$ - jump to the end of the line
x - delete a single character
dd - delete the entire line
yy - copy the current line
p - paste copied or deleted text below
u - undo the last action



**Markdown files in github:**
These are plain text documents formatted with lightweight symbols to create rich text.
The most common markdown document is README.md file.

Syntax Guide:
Headings - Use 1 to 6 hash symbols(#) before your text( e.g, #Title or ##Subheading).
Bold text - Enclose text inside double asterisks like **bold text**
Italics - Enclose text inside single asterisk like *italic text*
Links - Combine text in brackets with URL in parentheses: [Github] (https://github.com)
Lists - Use - or * followed by a space for bullet points or numbers like 1. for ordered items
Code blocks - Wrap snippets sections inside single backticks(```) to isolate the code blocks.
How to Create a Markdown File on GitHub
Navigate to your repository page on GitHub.
Click Add file and select Create new file.
Type a filename ending in .md (e.g, README.md or instructions.md).
Add your content using formatting syntax.
Click Commit changes... at the top right to save
